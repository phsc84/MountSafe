# MountSafe

Keeps files in an encrypted vault (a folder, typically on a NAS) and mounts it as a Windows network drive. Same cryptography and unlock methods as [RestoreSafe](https://github.com/phsc84/RestoreSafe): password, YubiKey, recovery code.

Status: specification, not implemented. See [docs/](docs/README.md).

Windows 11 64-bit only. Needs [WinFsp](https://winfsp.dev).
